# Dhanalaxmi Mart Review Assistant

> A Progressive Web Application (PWA) that helps customers confidently leave honest Google Reviews through an interactive, multilingual, guided experience.

---

## Project Status

**Current Phase:** Planning & Documentation

---

## Vision

Build the easiest Google Review guidance platform for retail businesses while remaining fully compliant with Google Business Profile policies.

---

## Problem Statement

Many customers scan a Google Review QR code but never complete a review because they:

- Don't know how to leave a Google Review.
- Are not signed in to Google.
- Don't know what to write.
- Feel uncomfortable typing on mobile.
- Prefer their local language.

This project solves those problems by guiding customers step-by-step before redirecting them to Google's official review page.

---

## Objectives

- Increase Google Review completion rate.
- Improve customer experience.
- Reduce review abandonment.
- Support multiple languages.
- Collect anonymous analytics.
- Follow Google Review policies.

---

## Privacy

The application:

- Does not access Google accounts.
- Does not store Google passwords.
- Does not automatically publish reviews.
- Does not modify Google Review pages.

Only anonymous usage analytics are collected.

---

## Google Policy Compliance

This application will:

- Guide customers through the review process.
- Allow customers to edit any AI-generated draft.
- Ask every customer for honest feedback.
- Redirect users to the official Google review page.

This application will never:

- Auto-submit reviews.
- Force a five-star rating.
- Offer incentives for reviews.
- Hide negative feedback.
- Generate identical reviews for every customer.
